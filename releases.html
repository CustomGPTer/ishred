Release notes

What changed in each version of IShred. The newest is at the top.

Version 1.0.2 26 November 2026Latest

  • Check for a newer version, More apps and Website in Settings, About. Each opens a web page in your browser; IShred stays offline.
  • Fixed: the weekly review reminder was pushed back a week every time IShred was opened, so it never came for people who use the app often.
  • Fixed: a fingerprint unlock now clears earlier wrong PIN tries, so one more slip no longer starts a wait.
  • Fixed: on Android 13 and later, IShred now asks to show notifications before an erase, so the progress notice and its Stop button appear.
  • Fixed: the result of deleting contacts waits until IShred is unlocked instead of showing over the lock screen.
  • Settings show readable names, and each list marks the current choice. About and reports show the real version number.
  • The bottom bar shows the selected tab with a pill behind its icon.

Version 1.0.1 25 November 2026

  • Reports count every byte written, even when a read-back check fails or an erase is stopped.
  • Settings and the app lock are saved all at once or not at all.
  • Folders you protect are also protected when files are picked through Android's picker.
  • The duplicate finder only reads files. The session timer stops when the session ends. Long file names fit on PDF pages.

Version 1.0.0 25 November 2026

  • First release. An offline file shredder and data eraser with eight overwrite methods, custom patterns, read-back checks, free-space overwrite, protected folders, duplicate and large-file review, signed reports and an app lock.

Checking your download

The file for version 1.0.2 is called IShred.apk. It is 362 KB (371,084 bytes). Its SHA-256 checksum is:

bf151ada3399a44663c4ef1b51c8579fbd81ace42b77e0869f7ef001ca3a20f1

On Windows, run certutil -hashfile IShred.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
